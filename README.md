🛍️ Customer Shopping Behavior Analysis

📌 Project Overview:-
This project analyzes customer shopping behavior using **Python, PostgreSQL, SQL, and Power BI**. The main objective is to understand customer purchasing patterns, identify sales trends, and generate useful business insights to improve customer satisfaction and business performance.

🛠️ Tools & Technologies:-
- 🐍 **Python:** Data cleaning, preprocessing, and Exploratory Data Analysis (EDA).
- 🐼 **Pandas:** Data manipulation and analysis.
- 🐘 **PostgreSQL:** Database storage and management.
- 💻 **SQL:** Querying data and extracting business insights.
- 📊 **Power BI:** Interactive dashboard creation and data visualization.

📂 Dataset:-
- 📌 Total Records: 3,900
- 📋 Total Columns: 18
- ⚠️ Missing Values: 37 (Review Rating column)

🔄 Project Workflow:-
1. 📥 Imported the dataset using Python and Pandas.
2. 🔍 Explored the dataset and checked missing values.
3. 🧹 Handled missing Review Rating values using median imputation.
4. ⚙️ Created Age Groups and Purchase Frequency columns.
5. 🗄️ Connected Python to PostgreSQL and loaded the cleaned data.
6. 💻 Performed SQL queries to answer business questions.
7. 📈 Created an interactive Power BI dashboard to visualize customer behavior.

💡 Key Business Insights:-
- 👩 Female customers generated slightly higher revenue than male customers.
- 🏷️ Some customers used discounts while spending above the average purchase amount.
- ⭐ Blouses and dresses received the highest product ratings.
- 🚚 Express shipping customers spent more on average than standard shipping customers.
- 🎯 Subscription customers showed higher spending and loyalty.
- 👥 Customer segmentation helped identify new, returning, and loyal customers.

🚀 Business Recommendations:-
- 💳 Encourage customers to subscribe through exclusive benefits.
- 🎁 Introduce loyalty rewards to increase repeat purchases.
- 🎯 Use targeted marketing campaigns for high-value customers.
- ⭐ Promote highly rated products.
- 🤝 Improve customer engagement and retention strategies.
